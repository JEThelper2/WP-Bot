Setup Guide

Connect your WordPress website to Sitepaw in under 5 minutes. Follow these steps, then message our WhatsApp number to finish.

About 5 minutes

Create a user, generate a password, install a small file

1

Create a Dedicated WordPress User (Editor Role)

Sitepaw needs its own WordPress user with Editor permissions — not your admin account. This limits what Sitepaw can do: it can manage posts and media, but cannot change your site settings, install plugins, or modify users.

  1. Log in to your WordPress admin at yourdomain.com/wp-admin
  2. Go to Users → Add New User
  3. Fill in the form:
    • Username: wpbot (or any name you'll remember)
    • Email: any email you control
    • Password: click "Generate Password" — you'll use the application password instead
    • Role: select Editor (NOT Administrator)
  4. Click Add New User
warning

Important: The role MUST be Editor. If you choose Administrator, Sitepaw will reject the connection. If you choose anything less than Editor, Sitepaw won't be able to post on your behalf.

2

Generate an Application Password

An application password is a special WordPress password designed for API access. It's safer than using your regular login password because it can only access the REST API.

  1. In WordPress admin, go to Users → Profile
  2. Scroll down to the Application Passwords section
  3. Enter a name: type wp-bot
  4. Click Add New Application Password
  5. Copy the password immediately — it's only shown once! It looks like: xxxx xxxx xxxx xxxx xxxx xxxx
lightbulb

Tip: If you don't see "Application Passwords", your site may need it enabled. Most modern WordPress sites (5.6+) have this built in.

3

Install the Sitepaw Plugin (Recommended)

Sitepaw includes a small WordPress plugin that lets us update your business information (phone, hours, address, prices) through a secure API. Without this plugin, Sitepaw can still post jobs and announcements, but business info updates won't work.

  1. Download the plugin file: wpbot-business-info.php (right-click → Save As)
  2. Log in to your WordPress admin
  3. Go to Plugins → Plugin File Editor (or use your hosting file manager)
  4. Navigate to the wp-content/mu-plugins/ folder (create it if it doesn't exist)
  5. Upload or paste the wpbot-business-info.php file into that folder
  6. The plugin activates automatically (mu-plugins don't need manual activation)
lightbulb

Alternative: Use your hosting file manager (cPanel, Plesk) to navigate to public_html/wp-content/mu-plugins/ and upload the file there.

Troubleshooting

"WordPress rejected the application password" expand_more

Common fixes:

  • Make sure you copied the full password including spaces
  • Try generating a new application password — the old one may have been revoked
  • Make sure the user account is active (not disabled)
"The login works, but that user can't edit posts" expand_more

The WordPress user you created doesn't have the Editor role. Go to Users in WordPress admin, click on the user, and change their role to Editor.

"I couldn't reach your site" expand_more

Double-check your site URL. It should start with https:// and be the same address you type in your browser to visit your site.

"That site is online, but I couldn't find WordPress on it" expand_more

Make sure the URL points to a WordPress site. If your site uses a different URL structure (like yourdomain.com/blog), try including the path.
