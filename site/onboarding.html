Create a Dedicated WordPress User (Editor Role)

WP-Bot needs its own WordPress user with Editor permissions — not your admin account. This limits what WP-Bot can do: it can manage posts and media, but cannot change your site settings, install plugins, or modify users. This is a security feature, not a limitation.

  1. Log in to your WordPress admin at yourdomain.com/wp-admin
  2. Go to Users → Add New User
  3. Fill in the form:
    • Username: wpbot (or any name you'll remember)
    • Email: any email you control (for password reset if needed)
    • Password: click "Generate Password" — you'll use the application password instead
    • Role: select Editor (NOT Administrator)
  4. Click Add New User
⚠️ Important: The role MUST be Editor. If you choose Administrator, WP-Bot will reject the connection for security reasons. If you choose anything less than Editor (like Author or Subscriber), WP-Bot won't be able to post on your behalf.

Generate an Application Password

An application password is a special WordPress password designed for API access. It's safer than using your regular login password because it can only access the REST API — it can't be used to log in to your WordPress dashboard.

  1. In WordPress admin, go to Users → Profile (or click your username at the top right)
  2. Scroll down to the Application Passwords section
  3. Enter a name: type wp-bot
  4. Click Add New Application Password
  5. Copy the password immediately — it's only shown once! It will look something like: xxxx xxxx xxxx xxxx xxxx xxxx (a string of letters and numbers with spaces)

Install the WP-Bot Plugin (Recommended)

WP-Bot includes a small WordPress plugin that lets us update your business information (phone, hours, address, prices) through a secure API. Without this plugin, WP-Bot can still post jobs and announcements, but business info updates won't work.

How to install:

  1. Download the plugin file: wpbot-business-info.php (right-click → Save As)
  2. Log in to your WordPress admin
  3. Go to Plugins → Plugin File Editor (or use your hosting file manager)
  4. Navigate to the wp-content/mu-plugins/ folder
    • If the mu-plugins folder doesn't exist, create it
  5. Upload or paste the wpbot-business-info.php file into that folder
  6. The plugin activates automatically (mu-plugins don't need manual activation)
Alternative method (via hosting file manager): If you have cPanel, Plesk, or another hosting control panel, use the File Manager to navigate to public_html/wp-content/mu-plugins/ and upload the file there.

Troubleshooting

"WordPress rejected the application password"

This means the password didn't work. Common fixes:

  • Make sure you copied the full password including spaces
  • Try generating a new application password — the old one may have been revoked
  • Make sure the user account is active (not disabled)

"The login works, but that user can't edit posts"

The WordPress user you created doesn't have the Editor role. Go to Users in WordPress admin, click on the user, and change their role to Editor.

"I couldn't reach your site"

Double-check your site URL. It should start with https:// (or http://) and be the same address you type in your browser to visit your site.

"That site is online, but I couldn't find WordPress on it"

Make sure the URL points to a WordPress site. If your site uses a different URL structure (like yourdomain.com/blog), try including the path.
